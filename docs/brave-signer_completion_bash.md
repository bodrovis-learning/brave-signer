To load completions in your current shell session:

	source <(brave-signer completion bash)

To load completions for every new session, execute once:

#### Linux:

	brave-signer completion bash > /etc/bash_completion.d/brave-signer

#### macOS:

	brave-signer completion bash > $(brew --prefix)/etc/bash_completion.d/brave-signer
